# prompts-bootcamp-Bradesco-DIO

Quero que você analise uma base de avaliações do app mobile Spotify para identificar quais os principais detalhes de feedbacks positivos e negativos.
O resultado será usado por o time de desempenho e satisfação para apoiar nas decisões de reparo de bugs e melhorias para o app.
A entrega deve conter executivo mas não tão formal, resumo de até 30 linhas, tabela simples com quantidade de feedbacks positivos e negativos, lista de insights ou recomendações.
O resultado será considerado bom se critério de qualidade, como clareza, utilidade, organização ou foco em ações.

Contexto: Estou trabalhando com feedbacks de clientes do app (Spotify).

Dados disponíveis: A base contém avaliações no app da playstore e appstore que você pode acessar pela internet para ver.

Critérios de análise: A IA deve classificar os feedbacks por titulos e maiores textos de avaliações.

verificar todas avaliações mais altas e as mais baixas com menos estrelas

Identifique os padrões de reclamação e faça um top 3 comentário de insatisfação mais falado.

crie temas e ideias rasas e curtas de uma futura melhoria com base no resumo das avaliações

Cuidados e restrições:
Use apenas os dados fornecidos pela internet dos dois sites {appstore e playstore}.
Não invente números, causas ou conclusões.
Não exponha dados pessoais ou sensíveis.
Se houver informação insuficiente, indique a limitação.
Use linguagem simples.
